# Stato lavori — GENKS Virtual Studio (FREE)

Progetto nuovo e autonomo in `genks-virtual-studio/` (Vite + React + TypeScript + Three.js).
Nessun file del sito precedente è stato modificato.

## Fatto
- Loghi: simbolo vettorializzato (99% corrispondenza pixel), wordmark raster originale + silhouette SVG.
- Intro saltabile, scena 3D procedurale con camera guidata dallo scroll, hotspot microfono/mixer/display.
- Transizione waveform → Beat Store, catalogo con filtri, player persistente con anteprime sintetizzate.
- Pannelli: registrazione, Mix/Master + invio remoto/upload simulato, licenze, carrello, checkout DEMO, esclusiva.
- Beat su misura (sequencer + form), pacchetti, admin demo (`#/gestione`), modalità leggera.
- Build, typecheck e lint puliti.

1. Far passare tutto `scripts/smoke.cjs` (ultimi controlli: mobile/tastiera intro).
